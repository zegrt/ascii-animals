## Findings

1. **Blocker — The optional log can still disclose personal data.** `Sources/OceanKit/Domain/Updates.swift:206`, `Sources/ASCIIAnimals/SystemWallpaper.swift:124`. The app logs Foundation errors as text. In an offline fixture, a file error for a volume root repeated the volume name in its human-readable message after both path fields had been scrubbed. A file URL for a home folder on a named volume also retained the home directory suffix when the literal home path contained spaces, and the standalone name of a one-character account survived the length check. A user who trusts the checkbox label can send those details. Strip home-path variants and redact account and volume names as standalone values. For error lines with free-form descriptions, keep safe structured fields or omit the line when the contents cannot be scrubbed reliably. Test the exact opt-in form with a Foundation error, an encoded home URL and a one-character account.

2. **Should fix — A failed check can still wait close to 20 hours.** `Sources/OceanKit/Domain/Updates.swift:429`, `Sources/OceanKit/Domain/Updates.swift:471`. A successful check followed shortly by a failed manual check leaves the successful timestamp governing the schedule. In a fake-clock test, a manual HTTP 502 ten minutes after a successful check produced no fetch on the next hourly tick. Mark a retry due after any failed check and clear it after a valid answer. Include a prior successful check in the retry test.

3. **Should fix — A malformed release can still produce “You're up to date.”** `Sources/OceanKit/Domain/Updates.swift:64`, `Sources/OceanKit/Domain/Updates.swift:489`. An HTTP 200 with an unparseable version tag and a placeholder relative release URL decodes successfully, takes the `.nothing` branch, and reports the running version as latest. The existing garbled test only exercises a body that fails JSON decoding. Validate the required version and release URL for a published stable release before treating the answer as valid. Test that a malformed stable release fails while an intentionally excluded draft or prerelease still produces no install offer.

4. **Should fix — A failed background check can allow a second download during an install.** `Sources/OceanKit/Domain/Updates.swift:439`, `Sources/OceanKit/Domain/Updates.swift:471`, `Sources/OceanKit/Domain/Updates.swift:517`. When a scheduled feed request is pending, the menu still offers the known release. If the person selects it and the feed then fails, the failure overwrites `.installing`. The person can now check again and accept the same update while the first download is pending. A fake host staged and committed twice when both callbacks were delivered. Normal termination after the first swap may prevent the second swap, but both downloads have already started, and a failed restart can leave both callbacks active. Keep the active install independent of feed failures and have a staging callback commit only while it still owns the install. The failure-state overwrite predates the OceanKit move.

5. **Should fix — A deferred automatic update can repeatedly download and lose its fallback notice.** `Sources/OceanKit/Domain/Updates.swift:416`, `Sources/OceanKit/Domain/Updates.swift:429`, `Sources/OceanKit/Domain/Updates.swift:526`. Launch now restores a cached release without calling the old notification fallback. When the cache is fresh and Settings remains open, ticks skip the install and never notify before the next feed refresh. A separate fixture opening a menu at the end of each download produced three full stage/discard cycles and zero notices. Restore the fallback for an already-known release when it cannot install, including when the final gate blocks it. Avoid restaging on every tick, for example by retaining the verified stage while the same release and settings remain applicable. Keep the fresh settings and window check at the swap.

6. **Minor — A literal plus sign in an opted-in log can reach the form as a space.** `Sources/OceanKit/Domain/Updates.swift:222`, `Sources/OceanChecks/UpdateChecks.swift:322`. Foundation emits a raw `+` in the query value. Its own query reader round-trips that character, but a form-query decoder reads it as a space. The current equality check only tests the Foundation round trip. Percent-encode literal plus signs and test round-tripping with form-query decoding. Verified the raw query locally. The GitHub form itself was outside the allowed checks.

7. **Minor — Update cleanup can stall the app UI on slow storage.** `Sources/ASCIIAnimals/SelfUpdater.swift:37`, `Sources/ASCIIAnimals/SelfUpdater.swift:79`, `Sources/ASCIIAnimals/SelfUpdater.swift:92`. The split moves the swap and recursive deletion of the staged archive and unpacked bundle from the worker to AppKit’s main thread. Cleanup also runs there when a user opens a menu during download and the swap is deferred. Keep the immediate surface check and rename together, and dispatch temporary-folder cleanup back to the worker. This is a source-level regression. Stall duration was outside the allowed checks.
