# Brief r3: updates, settings and diagnostics that tell the truth (audit a1, findings 4 and 10 in part)

Size: Content

Branch: meadow-r3, made from `meadow-t11` @ 971a216

## Objective
From the audit (`git show origin/review-a1:reviews/a1.md`): the updater decides "busy" from `NSApp.isActive` only and
can replace the app while Settings is open (Settings promises it waits); a failed or unparseable check is recorded as
a check and can say "You're up to date", then waits 20 h; the release cache and its ETag can disagree; notifications
are marked sent before they are; a relaunch that can't start still quits. A settings value decoded at an extreme
crashes the launch. "Report a Problem" puts diagnostics into a GitHub URL that leaves the Mac when the form opens,
before the person reviews them, with only partial redaction. Fix each at its cause. The director chose **not** to add
Developer ID signing now: keep the checksum and version checks and note the limit in `docs/DEVELOPING.md`.

## Do
1. **Prove each cause first** with a check that fails on 971a216 (fakes for the feed, the clock, the UI state and
   the notification centre). If a claim is wrong, say so with evidence.
2. **Updates:** a "can't interrupt now" state from the surfaces that matter (Settings open, even unfocused; a menu
   tracking; the card or welcome up), re-checked right before an automatic replacement, which also re-reads the
   auto-install preference; a check result that distinguishes up to date, failed and malformed, with a bounded retry
   after a failure (never "up to date" without a valid feed); the release and its validator stored as one record;
   "notified" saved only when the notification was added; relaunch failure keeps the old app running and reports it.
3. **Settings:** clamp before arithmetic in decoding and normalisation; `Int.min`/`Int.max` and old settings through
   the codec in checks.
4. **Diagnostics:** nothing leaves the Mac until the person has seen exactly what will be sent: a local review step
   first, then the GitHub form with only an allowlisted summary (version, macOS, display count and sizes, settings),
   log lines only if they choose, redacted (home path, user and volume names); off the main thread.
