# Brief r2: the system wallpaper always comes back (audit a1, finding 2)

Size: Content (large)
Board commit: the commit that adds this brief (main)
Branch: meadow-r2, made from `meadow-t11` @ 971a216

## Objective
"Match system wallpaper" is on by default: the app sets the macOS desktop picture to a still of the habitat and must
put the person's own picture back on quit, on turning matching off and on uninstall. The audit
(`git show origin/review-a1:reviews/a1.md`, finding 2; "Fix order" item 2) finds the restore keyed by display and image
URL only: Spaces with the same image but different options, a Space switch mid-render, a detached display, a failed
set, pruning of stills another Space still shows, a second restore forgetting the original, uninstall deleting the
recovery material after a failed restore. Make changing and restoring the wallpaper **one recoverable transaction**,
so a person's own wallpaper always comes back, on every Space and display the app touched.

## Do
1. **Prove the causes first**, each with a check that fails on 971a216, through an injected desktop-image API (a fake
   with Spaces, per-Space options, displays that come and go, failures on read, set and remove). If a claim is wrong,
   say so with evidence.
2. **The transaction** (the audit's "Fix and proof"): a journal of each original (URL and options) against the exact
   still installed, per display and Space as far as public APIs allow; settings, layout and the expected original
   re-checked at commit; recovery material kept until a restore is verified; reconcile on wake, display and Space
   changes; restore without a GPU; uninstall keeps the material and reports when a restore failed. Where public APIs
   can't give the guarantee (e.g. a Space never visited), limit what is changed and say so in the report and in
   Settings' help text (words to the manager for the director). Still filenames get a unique identity and a recorded
   order (the audit's finding 10, wallpaper part).
3. **Plan the live proof** for a separate macOS user account (not the owner's): two Spaces with the same image and
   different options, a switch mid-render, a display unplugged, matching off, quit, a restart after a kill, uninstall
   with one failed restore. The manager runs it with the director later.
