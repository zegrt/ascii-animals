# Brief t5: Meadow painter and the first still

Size: Content
Board commit: the commit that adds this brief (main)
Branch: meadow-t5

## Objective
Draw the Meadow in ASCII: flowers, grass, the breeze trail and the four butterflies, in both themes and in Calm,
and give the director a first still picture. This is plan Task 5, brought forward so the director sees the Meadow
early (board decision of 2026-11-19), so it runs before the meadow world (t3) exists.

## Output
Code on `meadow-t5`, the checks below passing, two stills (dark and light, 2560 × 1440) from `OceanTool
meadow-still`, and `reports/t5.md` describing what the stills show.

## Tools and sources
- `docs/plans/2026-11-19-meadow-3.1-plan.md`: Global Constraints, Review Focus 4, Task 5.
- `docs/plans/2026-11-19-meadow-research.md`: §4.1 (flower heads), §5.2 (drawing), §5.4 (palettes).
- The Web painter (`Sources/OceanKit/Web/`) and its checks, for the canvas, palettes, Calm, the `Grow` buffer
  pattern, and how 3.0 checked a painter on the GPU before its habitat existed.
- t1-2's code (merged on main): `Breeze`, `Meadowland`, `Flower`, `Butterfly`, `ButterflySpecies`.

## How this differs from plan Task 5, because there is no MeadowWorld yet
- The painter's input is `paint(land: Meadowland, butterflies: [Butterfly], breeze: Breeze, time: Double,
  viewport: CGRect, grid: GridSpec, theme: ThemeParams, into canvas: CellCanvas)`. t3 will wrap it for its world.
- The life-story drawing (caterpillar, chrysalis, the empty case) is NOT in this task; it moves to t4.
- The GPU check `meadowComposeDraws` goes through `encode(habitat:)` using a small test-only `CellPainter` wrapper
  inside OceanChecks (land + butterflies + breeze + this painter), as 3.0 did before its habitat existed.
- Add `OceanTool meadow-still <out.png> <W>x<H> [--light] [--calm] [--seconds S] [--seed N]`: lay out the land on one
  rect, fly a few of each species with `Butterfly.fly` toward random flowers for S seconds (default 20), then paint
  one frame and write the PNG. Set each butterfly's `scale` from the cell (`cell.width / 13`).
