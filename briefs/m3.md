# Brief m3: a ground colour per cell in the shared canvas

Size: Content
Board commit: the commit that adds this brief (main)
Branch: meadow-m3, made from main

## Objective
The Meadow port (docs/plans/2026-11-20-meadow-port-plan.md, task m3) needs a colour per cell for the ground: the
sketch's faint green hints in the black ground, and the shadows butterflies and flowers cast on bare ground (on
paper they carry the depth). Today `CellCanvas` has one `background` colour for the whole canvas, and `canvas_main`
paints it under every cell, including the 1 pt strip each block is inset from the grid. The director approved
changing this shared code ("Yes, change it") on one condition: **the sharks (Ocean) and spiders (Web) must look
exactly as they do now.**

Read the inventory's section 3 "Canvas" and section 4 item 7 (docs/plans/2026-11-20-meadow-port-inventory.md), and
how the sketch draws its ground and shadows (`git show origin/meadow-sketch:Tools/meadow-sketch/meadow.html`, the
ground cache and the cell drawing near the "Mosaic" code: the ground colour fills the whole cell, the block sits
inset on it, the grid line is drawn over the ground).

## Do
1. Give `CellCanvas` an optional per-cell ground colour (a packed array like `block`, grow-only, with a "no ground,
   use `background`" value), with a writer next to `put`. Keep every existing API and its behaviour.
2. In `canvas_main`, a cell with a ground colour shows it wherever it would show the background today: under the
   inset strip, in empty cells, under the grid lines and glyphs. Light mode and the dissolve apply to it exactly as
   they do to the background.
3. Ocean and Web never write it, and must render identically: prove it with the existing checks (`oceanStillUnchanged`,
   the Web cross-checks) and with `OceanTool bench --digest` fingerprints of Ocean and Web before and after, the
   same byte for byte.
4. A check in `CanvasChecks.swift` that a canvas with a ground colour in some cells shows it in those cells' strip
   and empty area and the plain background elsewhere (GPU render, as the existing canvas checks do), and that
   `clear()` resets the ground.
5. No allocation per frame; the buffer layout documented where `CanvasUniforms` is.

## Output and done when
Code on `meadow-m3`; `swift build` and `swift run -c release OceanChecks` pass (output in the report); Ocean and
Web digests unchanged (before and after in the report); `reports/m3.md`. CI typing rules: type long mixed-literal
expressions explicitly (Swift 6.3.3 on CI times out on them). No local folder paths in commits or files.
