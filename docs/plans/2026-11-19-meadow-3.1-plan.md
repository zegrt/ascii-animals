# Meadow (ASCII Animals 3.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Meadow habitat: our own butterflies flying over a meadow of swaying flowers, drawn in the same hand as the Ocean and the Web. Release it as ASCII Animals 3.1.

**Architecture:**
- The Meadow is a third `HabitatSim` that paints the shared `CellCanvas`, as the Web does.
- **Material:** a coarse breeze field the pointer writes into, plus flowers on damped-spring stems along the bottom of each screen.
- **Creatures:** butterflies flown by per-beat forces with a two-plane wing model, and one monarch life-cycle story at a time.
- **Painter:** turns material and creatures into cells with the spiders' machinery (supersampled shapes, `SKIN_RAMP`, position-keyed glyphs). No sprites.
- The simulation is built and recorded offscreen with `OceanTool` first. Menus, Settings and the welcome follow only after the owner approves the recordings.

**Tech Stack:** Swift 6 (Command Line Tools; CI compiles with Swift 6.3.3), SwiftPM, Metal (canvas compose already exists), AppKit/SwiftUI. Checks: `swift run -c release OceanChecks` (`--only <name>`, case-sensitive; `OCEAN_SKIP_GPU=1` skips GPU checks).

**Spec:** the Meadow sections of `docs/plans/2026-11-19-ascii-animals-design.md`, with the numbers in `docs/plans/2026-11-19-meadow-research.md`. The research's **Recommended parameters** table and §1.4, §2, §3.2, §4, §5 and §6 are the source of every value below. Where this plan and the research disagree, the owner decisions below win.

## Global Constraints

- **Owner decisions (2026-11-19):**
  - Always daytime.
  - Species: monarch, blue morpho, swallowtail (*P. machaon*, the Old World swallowtail), cabbage white. Real colours, toned down.
  - **Slow motion:** screen wingbeat = real × 0.28, capped at 3 Hz (monarch 2.6, morpho 1.7, swallowtail 2.0, white 3.0 Hz).
  - **Morphos sip flowers like the rest**, with every flower weight 0.5 and no fallen fruit. They still rest wings-closed.
  - **Life cycle: monarch only** (milkweed host, J-hang, jade chrysalis with gold dots).
  - **Courtship chases** are in: chase, rising spiral, the white's refusal posture.
  - **Caterpillar horn** (swallowtail osmeterium) is deferred until a swallowtail life cycle exists, because there are no swallowtail caterpillars in 3.1. It goes on the later list.
  - **No tall stems on high clicks:** a click blooms a flower in the ground band below the click's column.
  - Nothing is saved between launches.
- **Gestures** (design table): move → the breeze sways the flowers and butterflies veer; click → a flower blooms; hold the pointer still → a butterfly lands on the cursor, and moving makes it flutter off.
- **Several displays:** flowers along the bottom edge of each screen rect. With "One habitat across displays" on, butterflies cross between touching screens, monarchs preferring to (×3 weight). Off, each display has its own meadow.
- **Ocean and Web must not change:** `oceanStillUnchanged`, the Web cross-checks and the `bench --digest` canvas fingerprints stay identical.
- **Budget:** app CPU ≤ the Ocean's on the same displays (measured with `Tools/energy.sh`), WindowServer no higher, memory within ~10 % of the Ocean's. Never fewer butterflies or simpler motion to get there; cache and cull instead.
- **Fixed 60 Hz step,** at most 4 catch-up steps (`OceanClock`). Deterministic for a given seed via `WebRandom`.
- **No per-frame heap allocation in the painter.** Reuse buffers as the Web painter's `Grow` does.
- **CI's Swift 6.3.3 gives up on long untyped expressions.** Give literals and SIMD maths explicit types, and turn long check closures into named local functions (`func x() throws {…}; check("x", x)`).

### Task 1: Breeze and flowers (the material)

**Files:**
- Create: `Sources/OceanKit/Meadow/Breeze.swift`, `Sources/OceanKit/Meadow/Flowers.swift`
- Test: `Sources/OceanChecks/MeadowChecks.swift` (new; `meadowChecks()` registered in `Sources/OceanChecks/main.swift` like `webChecks()`)

**Interfaces:**
- Produces:
  ```swift
  public final class Breeze {   // coarse grid, one sample per 4 × 3 cells
      public init(bounds: CGRect, cell: CGSize)
      public func sample(_ x: Double, _ y: Double) -> SIMD2<Double>          // pt/s, bilinear
      public func write(_ x: Double, _ y: Double, vx: Double, vy: Double)     // pointer: velocity × 0.6, Gaussian radius 2.5 samples
      public func step(_ dt: Double, random: WebRandom)                       // decay (half-life 0.8 s), 5-point diffusion, ambient noise, gusts
  }
  public enum FlowerKind: String, CaseIterable, Sendable { case milkweed, coneflower, fennel, mustard, clover, daisy, dandelion, grass }
  public struct Flower {
      public var kind: FlowerKind
      public var base: SIMD2<Double>        // ground point, ocean space
      public var rows: Int                  // stem height in rows
      public var tip: SIMD2<Double>         // tip offset from rest (spring state)
      public var tipV: SIMD2<Double>
      public var f0: Double, zeta: Double
      public var bloom: Double              // 0 bud … 1 open; < 1 only while blooming
      public var bornAt: Double             // sim time a click bloomed it, or −1
      public var rect: Int                  // terrain rect it grows in
  }
  public final class Meadowland {
      public private(set) var flowers: [Flower]
      public init(random: WebRandom)
      public func layout(terrain: Terrain, cell: CGSize)
      public func step(_ dt: Double, breeze: Breeze)
      public func bloom(atX x: Double, y: Double, terrain: Terrain, time: Double) -> Int?   // index of the new flower
      public func dip(_ i: Int, impulse: SIMD2<Double>)                                     // a butterfly lands
  }
  ```
- Values:
  - **Ambient breeze:** value noise at 0.03–0.12 Hz, 10–40 pt/s, plus a natural gust of 60–120 pt/s every 20–60 s.
  - **Stems:** f₀ 0.7–1.2 Hz for tall stems (4–7 rows: coneflower, fennel, milkweed); 1.5–2.5 Hz for short ones (1–3 rows: clover, daisy, dandelion, mustard 2–4 rows). f₀ ∝ 1/height, ζ 0.08–0.15. Forcing = drag ∝ |v|·v of the breeze at the head, plus a per-stem phase so neighbours never move in lockstep.
  - **Layout per rect:** one plant every 3–5 columns along the bottom; grass in the bottom 1–2 rows; 6–14 "scattered" taller stems up to 40 % of the rect's height. Stems are always rooted on the rect's bottom edge.
  - **Bloom:** stem grows 1–3 cells in 0.6–0.9 s (ease-out), bud swells 0.5 s, petals open over 1.5–2.5 s, then a pollen sparkle for 1–2 s. Kind is chosen from the species' flower weights near that column. Rooted in the ground band of the rect under the click.

- [ ] **Step 1: Write failing checks**
  - `breezeHalfLife`: write 100 pt/s at a point, step 0.8 s with ambient noise and gusts off → sample is 50 ± 5 pt/s.
  - `breezeWriteIsLocal`: a write's effect 6 samples away is < 5 %.
  - `stemsRingAndSettle`: one tall stem, impulse, then calm air → it oscillates at f₀ ± 10 % and amplitude halves within 1/(ζ·2πf₀)·ln2 ± 20 %.
  - `flowersOnEveryRectBottom`: terrain `[0,0,2560,1440]` + `[375,1440,1800,1169]` → every flower base lies on a rect's bottom edge and inside that rect's x-range; none in the gap.
  - `bloomTimeline`: `bloom(atX:y:…)` → bloom reaches 1 between 2.6 and 4.2 s and never decreases.
  - `meadowlandDeterministic`: same seed → identical flowers after 20 s.

  - Walls: `Terrain.wallPush`.
- Speeds scale with `cell.width / 13`.

- **Drives** (research §6): hunger falls 1 %/s in flight and refills by nectaring; warmth falls in long flight and refills by basking; mate search for males. Every launch starts with ~30 s of brief basking.
- **States** (research §2):
  - **Approach:** slows to foraging speed within 2 wingspans, 1–3 short beats, ~25 % touch-and-go aborts.
  - **Nectar:** dwell 6–40 s per the species row, shorter on a known flower kind (constancy). The proboscis appears after 0.4–0.8 s; the swallowtail's forewings keep fluttering.
  - **Bask:** pose and duration per species.
  - **Rest:** wings closed 15–60 s with a slow open-close every 6–15 s. The morpho rests wings-closed with a 0.5 s flash every 10–30 s.
  - **Flush:** from pointer speed and distance (research Flush row, × boldness).
  - **Gusts:** airborne they drift, bank and beat +20 % when wind > 0.3 × airspeed; landed, wings close above ~60 pt/s and they flush above ~120 pt/s.
  - Landing dips the stem (`Meadowland.dip`, impulse ∝ size).
- **Flower choice:** species weights within a sensing radius of 8–15 wingspans. Morpho weights are all 0.5 (owner decision).
- **Density:** 1 butterfly per 0.4 Mpt² × `density`, cap 16 per screen. The species mix follows `ButterflyKind`'s share (white 35 %, monarch 25 %, swallowtail 20 %, morpho 20 %), restricted to the chosen species.
- **Patrol and perch:** whites patrol low loops; monarchs perch on tall flowers and sally out; preferred direction persists per the table.

- **Cursor landing:**
  - Trigger: the pointer is still ≥ 3 s (jitter < 2 pt) and inside the terrain.
  - The butterfly is chosen by the cursor weight row (swallowtail and white 2, monarch 1, morpho 0.5).
  - It spirals in over 2–3 loose circles, sits, opens and closes every 4–10 s, and puts its proboscis to the "skin".
  - Any move > 2–3 pt → escape burst (×2 speed, beat ×1.25, 0.6–1.2 s, climb per species).
- **Courtship:** about one encounter per 2–4 min per screen, between two of one species: a chase of 2–6 s, or a rising spiral of 3–8 s with a radius of 1–2 wingspans, then they part. A landed white may refuse with wings flat and the abdomen raised.
- **Crossings:** with `shared`, butterflies may fly through doorways between touching rects, monarch heading choice weighted ×3 toward the other screen. Without `shared`, never.
- **Life story (monarch only):**
  - One story per screen at a time, a new one every 3–5 min near a milkweed, and only if `.monarch` is among the species.
  - Stage durations (research §3.2): munch 60–120 s, wander 10–20, hang 15–30, pupate 3–5, chrysalis 60–120 (darkening for the last 15 s), eclose 4–8, pump 20–40 (wings 30 % → 100 %, ease-out), dry 20–40. Then the adult joins as a monarch, flies low and unsteady for ~10 s, and basks on its first landing.
  - Gait wave tail to head every ~1.2 s; the head dips every 0.4–0.6 s and the leaf loses cells in arcs from its edge; frass fades over 30 s; the empty case fades over 60 s.
  - A relayout (displays changed) ends any story in progress and starts the next one fresh on the new terrain, because flower indices change.
  - An emerging adult never pushes the count past the cap: if the screen is full, the oldest non-busy butterfly flies off the nearest outer edge first.

### Task 5: Meadow painter

**Files:**
- Create: `Sources/OceanKit/Meadow/MeadowPainter.swift`
- Modify: `Sources/OceanKit/Render/GlyphAtlas.swift`, only to append glyphs the painter needs that the atlas lacks (after every existing glyph, so Ocean and Web indices don't move)
- Test: `Sources/OceanChecks/MeadowChecks.swift`

**Interfaces:**
- Consumes: Tasks 1–4; `CellCanvas` (`put`, overlay layer from 3.0), `GridSpec`, `ThemeParams`.
- Produces: `public final class MeadowPainter { public init(); public func paint(_ w: MeadowWorld, viewport: CGRect, grid: GridSpec, theme: ThemeParams, into canvas: CellCanvas) }`.
- **Drawing** (research §5.2):
  - **Wings:** forewing and hindwing ellipses per species (swallowtail tail capsule, morpho broad lobes), sampled at (u, v / s) with 5 samples per cell as the spiders do.
  - **Wing interior:** block in the face colour; the glyph comes from a wing ramp keyed by a hash of quantised wing-local (u, v), so glyphs ride with the wing.
  - **Patterns:** veins and borders as `#%@` marks, margin dots `°·`, eyespots `o O @`.
  - **Edge-on:** |s| < 0.18 → a line glyph along the wing axis in the underside colour.
  - **Anti-flicker:** coverage class hysteresis of 0.1, one byte per cell in the butterfly's box. Tip offset `dy = −0.4 row · sin φ`.
  - **Body:** 1 × 3 cells on blocks with `SKIN_RAMP`; antennae `\ /` with `'` clubs; the proboscis glyph when nectaring.
  - **Flowers:** stems pick `/ | \` by local slope (the silk `lineGlyph` rule); heads per research §4.1; grass `,'/|\` by lean; the pollen sparkle; pollen-gold dust drifting off a flower a butterfly has just left, fading over 3–6 s (a trace).
  - **Breeze trail:** the pointer's breeze shown briefly brighter, sampled only at stems, grass and trail cells, never per screen cell.
  - **Life story:** caterpillar bands, the hanging J, the jade chrysalis with twinkling pollen-gold dots, the darkening, the crack, crumpled wings relaxing, frass `·`, the fading empty case.
- **Palettes:** research §5.4 values for dark. Light uses graphite on paper with species ink (saturation ≤ ~0.4); the cabbage white is a pale graphite block (214, 212, 204) with ink glyphs (96, 96, 90). Calm multiplies by `theme.brightness` in dark and mixes toward paper by `1 − brightness` in light, as the Web does. Background and grid match the Web's palettes.
- **Caching:** repaint only stems whose tip moved more than 0.05 cell; the rest of the ground band comes from a cached row set. Butterflies are culled per viewport.

  - `wingsDoNotFlicker`: a monarch hovering in calm air, 120 frames at 30 fps → no cell inside its box switches empty↔full more than twice per beat.
  - `edgeOnIsALine`: a wing forced to s = 0.1 → its cells hold a glyph from `|/\` and no block.
  - `whiteVisibleOnPaper` (Review Focus 4): light theme, a cabbage white → its cells' blocks differ from paper by ≥ 12/255 in luminance; and `meadowCalmIsDimmer`: dark Calm → mean ink luminance < 0.8 × normal's.
  - `stemsLeanWithTheBreeze`: a 60 pt/s breeze to the right → most stem cells above the base hold `/`.
  - `paintAllocatesNothing`: after a warm-up frame, painting 30 more frames leaves every reusable buffer's capacity unchanged (use the Web painter's pattern).
  - GPU `meadowComposeDraws`: paint a fixed scene through `encode(habitat:)` → the butterfly's body cell has its block colour and a flower head cell has ink pixels.
